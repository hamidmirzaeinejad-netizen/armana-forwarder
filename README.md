# فورواردر آرمانا (Armana Forwarder)

اپلیکیشن اندرویدی که پیامک‌های بانکی گوشی دفتر را به «آرمانا» (افزونهٔ وردپرسی، نسخهٔ ۱٫۱۲۳ به بعد) می‌فرستد تا آنجا به واریزی‌ها، هزینه‌ها، فروش‌ها و عملیات بانکی تفکیک و ثبت شوند.

- اتصال با یک QR (آرمانا › بانک › فورواردر › «ساخت QR اتصال») یا وارد کردن نشانی سایت و کد ۸ حرفی.
- فقط پیامک فرستنده‌هایی که انتخاب می‌کنید (بانک‌ها خودکار تیک می‌خورند) از گوشی خارج می‌شود.
- ارسال خودکار در ساعت‌هایی که آرمانا تعیین می‌کند (پیش‌فرض ۱۳:۰۰ و ۲۱:۰۰) + دکمهٔ «ارسال الان».
- هیچ پیامکی دو بار فرستاده یا ثبت نمی‌شود؛ اگر اینترنت نبود، بعداً خودش دوباره تلاش می‌کند.
- بدون هیچ کتابخانهٔ اضافه (فقط اندروید)، حداقل اندروید ۶.

## ساخت فایل نصب (APK)

### با GitHub (بدون نصب هیچ چیز)
1. یک مخزن **خصوصی** در GitHub بسازید و همهٔ این پوشه را در آن قرار دهید (Upload files یا git push).
2. در تب **Actions** کار «Build APK» خودکار اجرا می‌شود (یا دستی Run workflow).
3. بعد از حدود ۵ دقیقه، از پایین صفحهٔ همان اجرا، فایل `ArmanaForwarder-apk` را دانلود کنید؛ داخلش APK است.
4. برای نسخهٔ جدید: `versionCode` و `versionName` را در `app/build.gradle.kts` بالا ببرید. با زدن تگ `v1.0.1` فایل در Releases هم منتشر می‌شود.

### با Android Studio
پوشه را باز کنید (Open)، صبر کنید Gradle همگام شود، سپس Build › Build Bundle(s)/APK(s) › Build APK(s) یا `gradle :app:assembleRelease`.

> کلید امضای اپ (`app/armana-forwarder.jks`) داخل همین پوشه است تا همهٔ نسخه‌ها با یک کلید امضا شوند و به‌روزرسانی روی گوشی بدون حذف نصب شود. مخزن را خصوصی نگه دارید؛ در صورت تمایل گذرواژه را با Secretهای `FWD_KEYSTORE_PASSWORD` تغییر دهید.

## نصب روی گوشی
1. فایل APK را روی گوشی باز کنید و اجازهٔ «نصب از منابع ناشناس» را بدهید (Play Protect ممکن است هشدار دهد چون اپ از Play نیست: «نصب در هر صورت»).
2. اپ را باز کنید، QR آرمانا را با دوربین اسکن کنید و «اتصال این گوشی» را بزنید.
3. اجازهٔ خواندن پیامک را بدهید. اگر گزینه خاکستری بود: تنظیمات › برنامه‌ها › فورواردر آرمانا › منوی ⋮ › «اجازه دادن به تنظیمات محدودشده».
4. فرستنده‌های بانکی را تأیید کنید و «ذخیره». در صفحهٔ اصلی «خارج کردن از بهینه‌سازی باتری» را بزنید. روی شیائومی/هوآوی/اوپو «اجرای خودکار» اپ را هم روشن کنید.

## ساختار
```
app/src/main/java/ir/armana/forwarder/
  MainActivity.kt   صفحه‌ها: اتصال، خانه، فرستنده‌ها، گزارش
  SyncEngine.kt     یک ارسال: خواندن صندوق پیامک از نقطهٔ آخر، فیلتر فرستنده‌ها، ارسال دسته‌ای، تأیید دریافت
  Scheduler.kt      زمان‌بندی ارسال خودکار (JobScheduler + Alarm مجاز در Doze)
  Api.kt            ارتباط با آرمانا (?nam_fwd=pair|sync|unpair)
  SmsReader.kt      خواندن پیامک‌ها و تشخیص فرستنده‌های بانکی
  SentStore.kt      کلید پیامک‌های تحویل‌شده (جلوگیری از ارسال دوباره)
  Prefs.kt, Text.kt, Ui.kt, Components.kt
```
